# Мини-маркет

Небольшой каталог продуктов на React, TypeScript и styled-components.

## Как запустить

Нужны Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который появится в терминале. Проверка типов и сборка:

```bash
npm run build
```

## Что реализовано

- Светлая и тёмная темы с типизированным `DefaultTheme`. При первом открытии учитывается `prefers-color-scheme`, затем выбор сохраняется в `localStorage`.
- UI-кит: `Button` (4 варианта, 3 размера, состояние `loading`), `Badge`, `Card`, `Input`, `Grid`.
- В стилях используются transient props, `createGlobalStyle` и анимация `keyframes`. Цвета находятся в теме.
- Поиск по названию и фильтр по категории; если товары не найдены, показывается пустое состояние.
- Кнопка «В корзину» имитирует загрузку 700 мс и добавляет товар в открываемую корзину. В корзине можно изменять количество, удалять товары и видеть общую сумму. Это демонстрация без сервера, оформления заказа и сохранения корзины после перезагрузки. Если карточка исчезнет из-за фильтра во время загрузки, добавление отменяется.
- Сетка меняется с 1 на 2, 3 и 4 колонки в зависимости от ширины экрана.

## Структура

```text
src/
  components/ui.tsx           компоненты UI-кита
  components/ProductCard.tsx  карточка продукта
  components/Cart.tsx         содержимое корзины
  data/products.ts            данные каталога
  styles/theme.ts             две темы
  styles/styled.d.ts          типизация темы
  styles/global.ts            глобальные стили
  App.tsx                     каталог, фильтры и переключение темы
  main.tsx                    точка входа
```

## Styled-components и CSS Modules в этом проекте

Styled-components позволяет описывать стили рядом с компонентами. Через `ThemeProvider` удобно передавать цвета всей странице и переключать тему. Варианты кнопки задаются типизированными свойствами и условными стилями. В CSS Modules для этого можно использовать отдельные классы и CSS-переменные. CSS Modules не требует генерации стилей во время работы приложения. Styled-components добавляет зависимость и небольшие затраты во время выполнения, но упрощает работу с динамическими вариантами компонентов. Для этого учебного проекта я выбрал styled-components, потому что тема и UI-кит — основные требования задания.
